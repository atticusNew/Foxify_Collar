# Brand assets served by the demo service

Drop `atticus-lockup.svg` here (the "Atticus + finch" lockup, transparent background,
gold #d9ab01) and the service serves it at `/assets/atticus-lockup.svg` and switches the
app header to it automatically. Until the file exists, the header falls back to the
live-text lockup (Times serif "Atticus" + finch image).
