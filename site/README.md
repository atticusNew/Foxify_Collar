# atticustrade.com — landing page

Single self-contained `index.html` (no build step, no dependencies). Replaces the previous
site-builder deployment with messaging for the current product: Earn & Protect — embedded
one-tap collar protection for trading venues.

## Deploy (any of these)

- **Netlify / Vercel drop:** drag the `site/` folder in. Point the `atticustrade.com` DNS at it.
- **Render static site:** New → Static Site → this repo → publish directory `site` (no build command).
- **Replace the existing host:** upload `index.html` wherever the current site is served.

## Before going live

- Set the contact links (marked `SET CONTACT` in the HTML): scheduling link, Telegram, or a real
  mailbox for `hello@atticustrade.com`.
- Optional: add an OG image (`og:image` meta) — a frame from the demo video works well.

## Copy rules baked in

No APY claims, no fake logos/testimonials, no partner-implying language, refusal-honesty stated
as a feature, risk disclaimer in the footer. Keep it that way.
